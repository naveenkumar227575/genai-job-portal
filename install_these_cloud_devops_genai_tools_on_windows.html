🛠️ Cloud & DevOps Tools Guide

Comprehensive software checklist for GenAI Job Portal Project

Last Updated: November 2023 | For Windows 10/11 Development

💻

Core Development Tools

Python 3.10+
ESSENTIAL

Primary language for GenAI, LLM integration, and backend services

📥 Installation:

  • Download from python.org
  • Check "Add Python to PATH" during installation
  • Verify: python --version in terminal
Development Phase
Git
ESSENTIAL

Version control, collaboration, and GitHub repository management

📥 Installation:

  • Download from git-scm.com
  • Use default settings except:
  • Choose "Git from command line and 3rd-party software"
  • Set default branch name to "main"
Download Git
VS Code
ESSENTIAL

Primary code editor with extensions for Python, Docker, and cloud development

📥 Installation:

  • Download from code.visualstudio.com
  • Install Python, Docker, GitLens extensions
  • Configure terminal to use Git Bash
Download VS Code
Docker Desktop
ESSENTIAL

Containerization for consistent development and deployment environments

📥 Installation:

  • Download from docker.com
  • Enable WSL2 backend (Windows Subsystem for Linux)
  • Allocate 4GB RAM and 2 CPUs in settings
  • Verify: docker --version
Development Phase Deployment Phase
☁️

Multi-Cloud CLIs & SDKs

Azure CLI
ESSENTIAL

Manage Azure resources, deploy to Azure, and configure Copilot integrations

📥 Installation:

  • Windows: winget install Microsoft.AzureCLI
  • Or download MSI from docs.microsoft.com
  • Verify: az --version
  • Login: az login
Deployment Phase
AWS CLI v2
RECOMMENDED

Manage AWS services, deploy to EC2/EKS, and configure S3 for ML models

📥 Installation:

  • Download MSI from aws.amazon.com/cli
  • Verify: aws --version
  • Configure: aws configure
Google Cloud SDK
RECOMMENDED

Manage GCP resources, deploy to GKE, and use Vertex AI for GenAI models

📥 Installation:

  • Download from cloud.google.com/sdk
  • Run installer and initialize: gcloud init
  • Install kubectl: gcloud components install kubectl
Terraform
ESSENTIAL

Infrastructure as Code (IaC) for provisioning cloud resources across providers

📥 Installation:

  • Download from terraform.io
  • Extract and add to PATH
  • Verify: terraform --version
Deployment Phase
🤖

Microsoft Copilot Ecosystem

Power Platform CLI
ESSENTIAL

Develop, build, and deploy Power Platform solutions including Copilot Studio

📥 Installation:

  • Install via PowerShell: pac install latest
  • Or download from Power Platform CLI
  • Verify: pac --version
Development Phase
PowerShell 7+
ESSENTIAL

Automation scripts, Azure resource management, and Copilot deployment

📥 Installation:

  • Download from GitHub
  • Or: winget install Microsoft.PowerShell
  • Set as default terminal in VS Code
Azure Developer CLI (azd)
RECOMMENDED

Accelerate deployment of GenAI apps to Azure with pre-built templates

📥 Installation:

  • Windows: powershell -ex AllSigned -c "irm https://aka.ms/install-azd.ps1 | iex"
  • Verify: azd version
⚡

DevOps & CI/CD Tools

kubectl
ESSENTIAL

Kubernetes cluster management for container orchestration

📥 Installation:

  • Via Chocolatey: choco install kubernetes-cli
  • Or download from kubernetes.io
  • Verify: kubectl version --client
Deployment Phase
Helm
RECOMMENDED

Kubernetes package manager for deploying complex applications

📥 Installation:

  • Via Chocolatey: choco install kubernetes-helm
  • Or download from helm.sh
  • Verify: helm version
GitHub CLI (gh)
RECOMMENDED

Manage GitHub repositories, issues, PRs from command line

📥 Installation:

  • Download from cli.github.com
  • Or: winget install GitHub.cli
  • Authenticate: gh auth login
CI/CD Phase
Jenkins (Local)
OPTIONAL

CI/CD server for automation pipelines (can run in Docker)

📥 Installation:

  • Run in Docker: docker run -p 8080:8080 jenkins/jenkins:lts
  • Access at http://localhost:8080
  • Get initial admin password from container logs
📊

Database & Monitoring Tools

PostgreSQL
RECOMMENDED

Relational database for application data (can use Docker version)

📥 Installation:

  • Docker: docker run --name postgres -e POSTGRES_PASSWORD=password -d postgres
  • Or download from postgresql.org
Redis
RECOMMENDED

Caching and session management for GenAI applications

📥 Installation:

  • Docker: docker run --name redis -p 6379:6379 -d redis
  • Or use Redis for Windows from Microsoft Archive
Prometheus + Grafana
OPTIONAL

Monitoring and visualization for application metrics

📥 Installation:

  • Use docker-compose from Grafana docs
  • Access Grafana at http://localhost:3000 (admin/admin)
Monitoring Phase
📦

Package Managers

Chocolatey
ESSENTIAL

Windows package manager for automated software installation

📥 Installation:

  • Run PowerShell as Administrator
  • Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
  • Verify: choco --version
nvm-windows
RECOMMENDED

Node.js version management for frontend development

📥 Installation:

  • Download from GitHub
  • Install Node LTS: nvm install lts
  • Use it: nvm use lts
