# 🚀 GenAI Job Portal with Microsoft Copilot Integration

An intelligent job portal powered by Generative AI and integrated with Microsoft Copilot ecosystem.

## ✨ Features

- **🤖 AI-Powered Job Matching** - Intelligent candidate-job matching using LLMs
- **🔗 Microsoft Copilot Integration** - Seamless integration with Microsoft 365 ecosystem
- **🕸️ Smart Job Scraping** - Automated job listing aggregation
- **📊 Candidate Profiling** - AI-generated candidate profiles and insights
- **⚡ LangGraph Workflows** - Orchestrated AI agent workflows
